✨ Features

- 🏃 Jump over obstacles and keep running.
- 🦆 Duck to avoid obstacles.
- 🎮 Immortality Mode — toggle it on or off with the "J" key.
- 🏆 High Score — your best score is saved in your browser.
- 📱 Mobile Friendly — play on desktop or mobile browsers.
- 🚫 No Ads — enjoy the game without advertisements.

🎮 Controls

Action| Keyboard Control
Start the game / Jump| "Space" or "↑"
Duck| "↓"
Toggle immortality| "J"

«Note: When immortality is turned off, collisions can end the run normally.»
